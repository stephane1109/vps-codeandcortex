Annotation

Annotation du corpus

Import de add_expression_fr.csv, prévisualisation annotée et gestion du dictionnaire d'expressions de session.

Aide : le plus simple est de surligner, copier puis coller les expressions à transformer dans le dictionnaire. Par exemple, intelligence artificielle deviendra intelligence_artificielle.

Vous pouvez enregistrer votre dictionnaire d'expressions, mais vous pouvez également ajuster (supprimer) et enrichir (ajouter) un dictionnaire déjà annoté.

Vous pouvez réimporter un fichier d'expressions déjà annoté ; il doit impérativement être nommé add_expression_fr.csv.

CHD

Paramètres CHD

Si activé, le découpage recherche la meilleure frontière autour de segment_size avec priorité . ! ?, puis ; :, puis , puis espace ; un retour à la ligne clôture aussi le segment.

Ce filtre sert à l'affichage de l'AFC, AFC des variables étoilées, du concordancier, des nuages de mots, mais dans les stats les formes significatives à `p <= 0.05` apparaissent en vert et les formes au-delà du seuil d'affichage restent affichées en rouge dans le tableau.

CHD

Paramètres CHD (IRaMuTeQ-lite)

En manuel, vous fixez le nombre de classes avant l'analyse.

La CHD conserve son fonctionnement actuel : vous choisissez directement le nombre de classes.

Ce paramètre définit le seuil minimal d'UCE pour conserver une classe terminale.
